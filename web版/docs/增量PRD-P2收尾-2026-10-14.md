**US-P2-02 审计日志查询页（R-020 · E26 路由化）**
> 作为管理员，我希望在界面查询 append-only 审计日志（谁在何时做了什么、结果如何），这样安全敏感操作全程可追溯。

- AC1：新增审计查询路由端点（E26：`GET /api/audit?action=&result=&since=&until=&limit=&offset=`），挂 `require_session`（S4）；仓储层扩展 `AuditRepo.query`（audit_repo.py:72-102 现仅 action 精确过滤+分页上限 500）：**action 前缀匹配**（如 `restore.` 命中 restore.run/restore.inplace）、`result` 过滤、时间范围；`target` 搜索不做（§5-Q14）；
- AC2：审计页（主 PRD 页 12）列表按时间倒序 + 虚拟滚动；展示时间/操作/对象/结果；detail JSON 折叠展示且**脱敏原则不变**（写入侧已保证零凭据）；

- AC4：查询性能——audit_logs 表已有 idx_audit_ts/idx_audit_action 索引可命中；不为 target 建新索引（不做 target 搜索）。

**US-P2-03 retention 清理（R-020）**
> 作为管理员，我希望任务历史与日志按保留策略自动清理，这样 SQLite 与 /data 不会无限增长。

- AC1：jobs 行按 `retention.jobs_days`（默认 90，Q7 已裁决）清理，挂调度器**每日任务**；

- AC4：单日志截断（E27 tail 1MiB）既有机制不变——retention 管生命周期、截断管单文件大小，二者正交。

**US-P2-04 缓存占用查看与一键清空（R-021 · E25）**
