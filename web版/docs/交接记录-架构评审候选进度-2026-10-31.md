### 候选 5 · API 契约两份手写副本 —— 完成（**方式与原计划不同，先读这段**）

原计划「从 OpenAPI 生成 TS 类型取代手写」。**试过，不可行，已回滚**：

- 把 76 个同名类型改成 `S['X']` 别名后，`vue-tsc` 报 **82 个错误，其中 42 个 `possibly undefined`**
- 根因：**FastAPI 把带默认值的字段一律标为 optional**（`items?:`），而响应里它们必然存在 →
  生成类型比手写类型**更宽**，别名化等于降低类型安全
- `--properties-required-by-default` 也救不了：会把请求体的可选字段一并变必填（`force` 默认 false 是反例）
- **响应要必填、请求要可选，一个全局开关做不到**

现行方案：**类型仍手写（精度更高），用两道门禁拦漂移**：

| 门禁 | 拦什么 |
| --- | --- |
| `backend/tests/test_api_contract_sync.py` | `openapi.json` 必须与当前代码逐字一致；`schema.d.ts` 必须覆盖全部 schema 名 |
| `backend/tests/test_api_field_parity.py` | 前端同名类型的**字段名集合**必须与后端 schema 一致 |

- `709e0fd`：`scripts/gen-openapi.py`（离线导出）+ `frontend` 的 `gen:api` + 契约门禁
- `f1806e2`：字段名门禁 + 修两处**真实漂移**——`JobOut` 缺 `repo_id`、`SnapshotFileSearchResponse` 缺 `truncated`

**重新生成**（改后端 schema 后必做，否则门禁红）：

## 4. 踩过的坑（照做可避免重复）

1. **grep 自匹配**：门禁文件里写了正则字面量，`grep -l` 会把它自己判成违规。已在 bash 与 pytest 两侧显式排除。
2. **别用手写 `"""` 状态机跳 docstring**：遇非常规引号会失步，曾导致某文件 63 行之后**完全不被扫描**（门禁静默盲区）。要排除散文就按行内容窄排除。
3. **PowerShell 双引号里的 `$HOME`/`$?` 会被展开**，且反斜杠会丢（`C:\Users\x` → `C:Usersx`，曾因此造出一个含 U+F03A 的怪目录）。给 bash 传命令用**单引号**。
4. **写入后要归一 CRLF**：Windows 侧 Python 写出 CRLF，而仓库存 LF，否则整文件重写。
5. `docs/` 指针校验只认**带斜杠**的路径式引用；正文里的《文件名.md》是散文提名，不是链接。
6. **111 个提交未推送到任何远端**（`github` / `origin(cnb.cool)` 两个远端都在，main 领先 111）。
   这是当前最大的丢失风险，建议推一次或建本地裸镜像。
